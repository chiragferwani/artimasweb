# Website Build Prompt — Artimas 26-27 (Theme: The Four Yugas)

Use this as a single, complete brief to hand to a designer/developer or an AI website builder.

---

## 1. Core Concept

Build a website for **Artimas 26-27**, the flagship fest of the college club **Aimsa**. The entire website — visuals, copy, navigation, transitions, iconography — must be built around the concept of the **four Yugas** of Hindu cosmology: **Satyuga, Tretayuga, Dwaparyuga, and Kalyuga**. This is not a decorative theme applied on top of a generic template — the Yuga concept should drive the structure, storytelling, and visual language of every page.

Treat the fest itself as if it exists *within* this cosmic timeline — the festival is framed as the point where all four ages converge, or as a portal/event that lets the four eras collide in the present (Kalyuga), which is a natural narrative hook for "why is this happening now."

---

## 2. Theme Guidelines (must be followed strictly)

### 2.1 Narrative framing
Each Yuga should be treated as a **distinct era with its own identity**, not just a color swatch. For each Yuga, define and consistently use:
- **Core virtue/element** it represents (Satyuga = truth & purity, Tretayuga = duty & sacrifice, Dwaparyuga = duality & strategy, Kalyuga = chaos & conflict — refine as desired)
- **A signature color palette** (e.g., Satyuga: whites/golds; Tretayuga: earthy greens/ochres; Dwaparyuga: blues/deep purples; Kalyuga: reds/blacks/greys)
- **Key events and characters** associated with that era (this content must be researched and written accurately, then adapted into short, fest-friendly narrative blurbs — not textbook paragraphs)
- **A texture/motif** (e.g., Satyuga = lotus/light rays, Tretayuga = bow & arrow/forest, Dwaparyuga = chakra/mace, Kalyuga = cracked earth/storm/embers)

### 2.2 Visual language
- The overall design should feel **mythic, cinematic, and premium** — not clip-art religious, not cartoonish.
- Use gradient transitions or section breaks that visually suggest **moving through time/ages** (e.g., scroll-based transition from bright/pure tones toward darker/chaotic tones as the user moves from Satyuga to Kalyuga).
- Typography should feel ancient-meets-modern: a bold display font with mythic character for headings, paired with a clean readable font for body text.
- Iconography, dividers, and background textures should draw from Indian mythological art motifs (mandalas, temple carvings, weapons, cosmic symbols) — stylized, not literal or cluttered.
- Avoid generic "festival poster" clichés (neon EDM style, random confetti) — this fest's identity is mythological gravitas, not a typical DJ-night aesthetic.

### 2.3 Tone of writing
- Copy should sound **epic and inviting**, like the opening of a saga — confident, a little dramatic, but not overwritten.
- Avoid dry Wikipedia-style descriptions of the Yugas; adapt facts into short, punchy, fest-appropriate storytelling.

---

## 3. Site Structure

### 3.1 Pages
1. **Home**
2. **Events**
3. **Artimas 25-26** (previous edition / legacy page)
4. **Contact Us**

### 3.2 Navigation
- A persistent navbar/header across all pages with these four links, styled to match the mythic theme (e.g., subtle glow, animated underline, or icon per section).
- Consider a footer with quick links, social handles, and the Aimsa club branding.

---

## 4. Page-by-Page Requirements

### 4.1 Home Page
- **Hero section**: Fest name "Artimas 26-27" prominently displayed with a tagline that ties into the Yuga concept (e.g., framing the fest as the convergence point of all four ages). Include dates/venue placeholders if not finalized.
- **Yuga introduction section**: A visually distinct block for each of the four Yugas (could be four cards, a horizontal scroll, or a timeline layout) introducing:
  - Name of the Yuga
  - Its core theme/virtue
  - 1–2 major events from that era
  - 1–2 major characters from that era
  - A "learn more" interaction (expandable card, modal, or link) for users who want deeper mythological detail
- **About Aimsa/Artimas** section: brief description of the club and the fest.
- **Highlights/teaser section** for the 9 events (even before names are finalized, this can use placeholder event slots styled by Yuga, e.g., "Event 1 — [Yuga name TBD]") with a CTA button to the Events page.
- **Countdown timer** to the fest (optional but recommended).
- Smooth scroll-triggered animations that reinforce the passage-through-ages narrative.

### 4.2 Events Page
- Grid or timeline layout displaying all **9 events**.
- Each event should be visually **tagged/mapped to one of the four Yugas** (this mapping should be decided once event names are finalized) so the Yuga theme continues here — e.g., color-coded borders/backgrounds matching that Yuga's palette.
- Each event card should include: event name (placeholder until finalized), short one-line description, Yuga tag, and a "View Details" button.
- Clicking an event card **redirects to that event's dedicated page** (see 4.2.1).
- Filter or sort option by Yuga category (optional enhancement).

#### 4.2.1 Individual Event Pages (×9, dynamically templated)
Each event should have its own page/template with:
- Event name and Yuga theme banner (styled using that Yuga's palette/motif)
- Full event description and rules
- Date, time, venue, team size (placeholders until finalized)
- A short mythological tie-in blurb connecting the event's spirit to its assigned Yuga (e.g., a strategy-based event tied to Dwaparyuga's theme of duality/strategy)
- Registration button/link (placeholder if registration isn't live yet)
- Organizer/coordinator contact details for that specific event
- Back button to return to the Events page

### 4.3 Artimas 25-26 Page
- Acts as an **archive/legacy page** for the previous edition.
- Sections to include: recap/highlights, photo gallery placeholder, list of past events held, winners/standout moments (if available), and a short "the story so far" narrative that sets up why 26-27 continues the saga.
- Should visually feel like a "chronicle" or "record from a past age" — reinforcing the Yuga storytelling (e.g., styled like an ancient scroll/tablet aesthetic, distinct from the more vibrant present-day pages).

### 4.4 Contact Us Page
- Contact form (name, email, subject, message).
- Direct contact details for the Aimsa club (email, phone, social media handles).
- Location/venue map placeholder if applicable.
- Optionally, list key coordinators/points of contact for different event categories.
- Keep this page cleaner/simpler while still matching the overall visual theme (avoid overloading a functional page with heavy imagery).

---

## 5. Functional & UX Requirements
- Fully responsive across mobile, tablet, and desktop.
- Smooth page transitions/animations that reinforce the "moving through eras" concept (avoid overdoing it to the point of hurting load speed or usability).
- Clear, accessible navigation — the mythic theme should never make it harder to find Events, Contact, or registration info.
- Placeholder content structure should be easy to swap out once the 9 event names and details are finalized (i.e., build with a repeatable template for event pages, not 9 one-off custom designs).
- Fast load times — avoid theme-heavy assets (videos, large background images) that slow down the site.

---

## 6. Deliverable Expectations
- All four Yugas should be **immediately recognizable and distinguishable** from one another purely through visual language (a user should be able to tell which Yuga a section represents even without reading the label).
- The site should read as **one cohesive mythological universe**, not four disconnected color themes stitched together.
- Content about the Yugas (events, characters) must be **accurate to the source mythology** first, then adapted for tone — do not fabricate mythological facts.
